\# DXT Documentation



This directory contains the engineering documentation for the DXT platform.



\## Structure



\- architecture/ — Platform architecture and system design.

\- governance/ — Canonical object registry, standards, and governance policies.

\- ontology/ — Business concepts, conflict ontology, and decision taxonomy.

\- workstreams/ — Major implementation workstreams and milestone history.

\- decisions/ — Architecture Decision Records (ADRs) explaining significant design decisions.



Documentation stored here should describe the platform, not duplicate implementation details already defined in SQL or WeWeb.
